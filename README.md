# 30 Days of Cyber

30 days. 30 cybersecurity projects. Built from scratch, one day at a time.

---

## What Is This?

A 30-day community challenge where I build one hands-on security project every day — starting from the basics and climbing toward real offensive/defensive scenarios. No copy-pasting, no shortcuts. Just research, learn, build, break things, and repeat.

By Day 30: a real portfolio of tools I built myself.
